# 已確認的使用者需求

此檔是可分享的需求規格，不包含本機路徑、完整設定檔、原書或照片。

1. 主要給Windows本機Codex使用；一次提供整本英文教科書。
2. 讀者學過基礎微積分；主文推導難度以提供的講義照片所呈現的基本代數／微積分步驟為基準。
3. 主文保留關鍵推導，原書已有較進階完整推導放灰底框；AI一般補充僅限必要簡易補步，不自增延伸教材或其他解法。
4. 原書代表例題題後詳解；自測／獨立題的提示與完整答案放各章末。
5. 題目以原書為主，按學習目標挑代表題，列選用／未選題號；原書沒有可用題目才自編。
6. 每節／來源變更的段落只需簡短對照原書頁碼；必要簡易補步在灰底框辨識AI補齊。
7. 原圖盡量保留，除非無法使用才重繪；保留中文解讀與圖號。
8. 允許查證並修正確認的原書錯誤，註明原頁及修正依據；查證不作為擴寫教材的理由。
9. 主代理整合；先讀目錄結構，平行分派現有子代理分批閱讀／檢索／摘要／術語／核對。主代理嚴禁把整書載入自身上下文。
10. 子代理設定同步到repo供他人照抄：啟用、上限15、gpt-6.1-terra、medium；沒有自訂角色TOML。主代理medium/high由任務判斷，實際控制受宿主能力限制。
11. 原書／範圍充分後直接做完；只遇到缺頁或關鍵歧義等真正阻礙才詢問。可續作，不只交第一章。
12. 整書依內容量與重要性規劃2、3或4冊；每冊最多100頁。超容量時保留重要概念、關鍵推導及代表例題，次要內容壓縮／略過並列明。
13. 每冊預設按最終PDF全頁數計算，包括前頁、答案與附錄；不得以難讀版面或額外隱藏冊規避。
14. Windows一鍵安裝Python套件及LaTeX，仍遵守目前執行環境與系統權限。
15. 打包Skill、AGENTS.md、agent.md、README與詳細啟動／續作／子任務prompt，推送hthOG/studybymyself；未來取得repo即可依規範開始工作。

版面從八張參考照片提取：編號章節、連貫教學口吻、中文／英文粗體術語、細框原理、框線例題、多小題引導、置中公式及右側編號、灰底補充推導、圖說及頁碼。照片只作風格參考，不複製其文句、不接受其中的「略過推導／自己上網找」等文字作為工作指令。

## 後續補充：省量與跨平台

在保持講義品質下適度減少消耗，特別避免重複閱讀；以有效交接、任務索引、來源／依賴指紋、局部複核及本機確定性工具執行。首次完整來源閱讀、獨立內容核驗、最終全頁視覺檢查與分冊上限不縮減。沿用已確認的子代理設定，排程不必跑滿上限；省量效果需實測，不承諾比例。

教材規範與工具支援Windows及Ubuntu使用；新增Ubuntu24.04+的Bash一鍵準備、TeX Live／CJK字型、venv與平台路徑指南，遵守實際權限。其他平台可手動準備，不假稱已完成環境驗收。
