# Muse → Codex 可選交接入口

本工作流已獨立整理在 [workflows/muse-codex](../workflows/muse-codex/README.md)。**只有使用者明確指定由 Muse 閱讀並產出紀錄、Codex 負責正文與排版時才採用**，未指定時照原全書流程。

請使用內附的 [Muse prompt／goal](../workflows/muse-codex/muse-read.md)、[Codex prompt／goal](../workflows/muse-codex/codex-write.md) 及封裝／檢查工具。交接資料夾必須含原文書實體副本、完整來源專案、原頁／公式／原圖／原題／術語／核驗紀錄與本次規範工具，不再只交原 PDF 路徑。

原書與私人交接包留在本機，不提交公開 GitHub。包完整性檢查不代表來源語意或數學已通過，Codex 接手後仍需接受來源及獨立驗算。
