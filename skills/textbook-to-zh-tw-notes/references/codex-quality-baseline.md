## 可落實的寫作決策

| Codex 講義觀察位置 | 可觀察的決策 | 新稿如何做到 |
|---|---|---|
| 第1冊p.3、5–6 | 先提出牛頓逃逸圖像的不足，以資訊傳遞接到因果問題 | 章首提出具體問題；推導後明說該模型解決了什麼、尚不能證明什麼。不能只有章名與公式 |
| 第1冊p.7–10 | 先講態計數與固定量，再由能量接到壓力，區分兩種粒子質量角色 | 新量在使用前定義；微分時標固定變數；同名或相似符號須有角色對照，不能只抄最後式 |
| 第1冊p.20–22 | 題解保留微分次序、方向與適用條件，檢查量綱和源外跡 | 完整回答各小題；計算中說明為何先微分後施加條件；缺物體大小就不虛構具體力值 |
| 第1冊p.23、28–30、39–41 | 先固定號誌與單位，再區分座標時間、固有時及仿射參數 | 建立符號約定，求導標明參數；不能把沿一條世界線的結論任意套用其他觀察者 |
| 第1冊p.34–35、第2冊p.30 | 幾何平滑的推導與原書給定的量子結果分開 | 清楚標哪些實際推得、哪些是來源引用。列出溫度公式不等於已完成量子場論證明 |
| 第2冊p.18–20、25–26 | 模型條件、守恆與分部積分連起功率與壽命，保留極限檢查 | 公式前後有適用條件及用途；關鍵積分、邊界項與係數能重做，核驗留實際輸入／輸出 |
| 第2冊p.40–43、52–55 | 由有效勢的可達區連到題解，圖像比較固定與改變的條件 | 不只貼圖；說明軸、控制參數、連通區域及無刻度時不能定量讀出的資訊 |
| 第3冊p.3–4、11 | Kerr先定義量綱、交叉項分量；固定參數取極限，另給無因次量的對照 | 逐項核對交叉項的2、自然單位還原、歸一化轉換、根的分支及分母非零。不能見符號相似就替換 |
| 第3冊p.6、9、13–14 | 訂正附實際差異與可重算檢查；AI簡易補步保留端點條件 | 候選與正式採用分開；先證據、後修正、再重驗受影響內容。補步後回正文，不發展額外教材 |
| 第3冊p.17–21、第4冊p.26 | 章末以依賴鏈、帶條件重點及原題提示／完整解答組織 | 每題的目標、條件、問項與答案一一對應；章末是能使用的複習材料，不能只重排目錄 |
| 第4冊p.12、32、41 | 原圖證據界線、跨章倒數縮放及邊界符號明示 | 分清示意與數據、給定與推得；跨章慣例要換算，不靠記憶統一改寫 |

這些是教學呈現的觀察，不代表表中每個物理結論已在本次重新證實。[局部示範](../../../examples/codex-style/lesson.md)把「目的→定義→操作→結果解讀→練習解答」寫成可讀小節，供沒有原PDF的後續代理直接校準。

## 驗收以能重建推理為準

抽取一個尚未編寫的原書小節及原題，讓作者依新規範試寫，核驗者另由原頁求解。審查者實際回答：為何引入這個量？假設在哪一步使用？每個關鍵變形為何成立？結果描述誰測到的什麼？能否依答案重做原題？對照的是具體段落與推理缺口，不是字數、公式數、框數或自評分數。

修稿後再審受影響範圍，再完成全書。現有自造範例與單元測試只驗工具／局部示範，不能冒稱Muse Spark已達Codex品質。公式核驗詳見[核驗規範](formula-verification.md)；任何模型及檢查器都不提供零錯誤保證。
