# LaTeX、公式保真與 PDF 驗收

## 分離教學內容與版面

從專案根編譯 `layout/main.tex`；其中用 `\input{content/chapter.tex}` 與 `\input{content/answers.tex}` 引入正文。重要公式與每段重要推導存成獨立 `content/math/*.tex`，正文 input，避免排版時重新轉寫公式。公式檔可含完整 equation/align 環境與 label；正文旁寫來源與逐步理由。

同一式在章末公式表再次出現時引用同一檔，或引用其編號；不另維護一份手抄式。較長推導可拆成數個鎖定公式檔，讓運算理由穿插其間。簡短行內記號可直接放正文，正文一起鎖定。

內容核驗後執行 lock。排版只改 `layout/`：頁邊、字體、段距、框樣式、caption、浮動方式。換行需求優先調整環境或版面；確需修改內容中的 align 換行，也屬內容變更，必須回退核驗，不可當成「只是格式」繞過雜湊。

雜湊只能偵測修改，不能判斷原公式正確。先對照原頁核對公式，再鎖定。鎖定後仍要核對 PDF 的向量、分母、指數、上下限、負號、撇號與等號是否真的顯示正確。PDF 文字抽取通常不能還原數學結構，不能作為唯一公式驗證。

## 工具與字體

模板為原創的 A4 單欄 XeLaTeX／xeCJK 講義骨架；`main.tex` 沒有正式教學內容，不應直接當成果交付。先填入正文章、答案與書目，不留空 input。

依執行環境檢查 `xelatex`、`latexmk`、`pdftoppm`；可使用宿主提供的 LaTeX 編譯工具，使用前發現其實際能力並保存回傳診斷。不假設本機一定有 TeX Live。Poppler 只負責預覽，不會編譯 TeX。缺少工具時優先使用已提供的編譯能力；若仍不可用，說明限制並保留可編譯專案，不冒稱 PDF 已完成。

檢查實際安裝的繁體中文字體。模板預設 `Microsoft JhengHei`，若不存在，改為現有的 Noto Serif CJK TC 等字體；不把簡體字型名稱當作繁體字型保證。使用 fontspec/xeCJK 時不混用舊式 inputenc/fontenc 設定。字體缺字 warning 必須檢查實際輸出。

編譯可用參數陣列呼叫，例如從專案根：

```text
latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build layout/main.tex
```

或依序執行至少兩次 XeLaTeX，直到目錄與交叉引用穩定。不能只因存在舊 PDF 就認定本次編譯成功；檢查退出碼、時間戳、來源版本與 log。保存實際命令與結果。不要使用會自行安裝系統套件或啟用 shell-escape 的上游腳本。

## 長文排版

以可閱讀正文為主，預設 11pt 左右及適當行距。推導使用 equation/align，不套用上游 Markdown 禁用 LaTeX 環境的規則。來源註記用可讀的正文／框標籤；不能只用顏色區分原書與補充。黑白列印仍須辨識。

圖說在圖旁、表格保留單位與註腳；長表使用 longtable/tabularx。長推導分組而非縮到難讀尺寸。篇幅不足先回內容規劃，依重要性壓縮次要內容；關鍵推導、假設及必要來源標記不可刪掉。內容鎖定後排版不得摘要化。圖寬以實際標籤可辨為準，不硬套每圖固定比例。避免所有節前強制換頁與過多僵硬浮動位置。

優先保留原圖；只有原圖確實無法使用時，精確物理示意圖才用TikZ／SVG／繪圖程式重繪。SVG 可用現有工具轉 PDF，記錄過程；不能假定 graphicx 原生支援 SVG。正文與公式維持可搜尋文字，不以整頁點陣圖冒充可編輯 LaTeX。

## 最終 QA

1. 比對雜湊：content 所有檔案及來源核驗證據一致；新增或刪除公式檔同樣要攔下。
2. 編譯 log：無錯誤、缺字、未定義命令／引用、重複 label；overfull/underfull 等警告逐項判斷，實際溢出要修。
3. 執行 prepare-pdf-review，再將所有 PDF 頁轉為約 140–180 dpi PNG，在可閱讀尺寸逐頁查看。先檢查全頁版面，再放大長式與圖表；接觸表只能輔助導航，不能取代細看。
4. 逐頁檢查：中文字與英文字、所有負號／分式／向量、圖軸／箭頭／圖說、來源標記、裁切／溢出／重疊、跨頁推導、提示與答案分離、頁碼與目錄。
5. 回看原頁：重要公式、例題數值及圖表關係與原文一致，AI 補充仍有標籤；來源對照的原頁碼不是講義頁碼。
6. 寫 `qa.json` 的實際檢查紀錄及 `quality-report.md`，全書執行book.py check；各冊全部頁面都須通過，不使用舊單PDF的release冒充多冊通過。

編譯失敗或關鍵內容待核實時可交工作稿，但標明「未完成」與具體缺口，不給正式完成宣告。遇到可自行修正的錯誤持續處理；只有缺失原書頁、不可讀符號或必要外部條件才請使用者補充。

## 跨冊引用與編號

各冊獨立編譯，章稿須明設原書章號（例如章首先 `\setcounter{section}{3}` 再 `\section{...}` 得第4章），並在檔案索引記錄對照；不讓每冊都從第1章重號。各章使用唯一label前綴。跨冊引用以明確的冊／章／原書頁碼文字標示，或另建並核對外部標籤機制；不得留下無法解析的 `\ref`，不得靠硬改公式編號掩蓋錯配。分冊計頁仍包含目錄、空白換頁與章末解答。

## 跨平台與局部修訂

Windows與Ubuntu同用XeLaTeX模板；Ubuntu採TeX Live、Noto CJK TC與TeX Gyre字型。路徑用專案相對路徑、ASCII檔名及大小寫一致的input。先用本機程式篩log、統計頁數，再只讀相關錯誤／差異；不把整冊TeX重貼給排版代理。純版面變動可保留未變的來源與數學證據，但受影響冊重編後仍逐頁核驗，不能沿用舊PDF視覺通過。
