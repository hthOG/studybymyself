# 來源閱讀與定位

## 建立可信來源

記錄書名、作者、版次、年份、原始檔路徑與 SHA-256。書目資訊讀不到就填未知，不從檔名猜版次或出版年。來源改變時，比對雜湊，重新定位受影響頁面，作廢相關閱讀、公式及 PDF 核驗狀態。

章界以目錄、章首標題、上一章結尾及下一章開頭交叉核對。章與章可能共用同一 PDF 頁；只收錄目標章的區域，範圍寫入 `scope_note`。不把頁數硬切或自動書籤偵測的結果視為章節事實。

兩套頁碼獨立保存：

- `pdf_page`：檔案第幾頁，1 起算；工具接受 0 起算時只在呼叫邊界轉換。
- `printed_page`：實際頁面上印的頁碼，字串保存羅馬數字等；看不到就 `null`。

逐頁確認印刷頁碼；固定偏移只可作待確認候選值。原書印刷頁碼、PDF 頁序與講義頁碼不得混用。引用例如：`[B1，第 7 章 §7.2，印刷 p.158；PDF 第 174 頁，式 (7.6)]`。只有 PDF 頁序時明寫 `印刷頁碼未能確認`。

EPUB／HTML 無固定頁碼時以章節、檔內 anchor、原式／圖編號定位，不虛構紙本頁碼。工作契約的 `units` 此時是有穩定 anchor 的來源區段，`kind=epub_anchor`，`pdf_page=null`；原始檔仍計算雜湊。必要時保留可重現的段落編號副本。

## 子代理逐批閱讀與原圖覆核

1. 抽出本章逐頁文字，保留頁界；渲染原頁，查看欄序、註腳、側欄、表格、圖說與跨頁接續。
2. 依原書小節順序完整讀取所有選定單位。對每個單位記 `text_review`、`visual_review`、閱讀證據及新發現的來源項目。
3. 文字層正常仍需讀原頁。物理公式可能抽漏負號、向量、上下標、希臘字母、分式、積分上下限、撇號與等號；不能以可搜尋為可靠性的代理。
4. 掃描或亂碼頁使用現有 OCR／視覺能力，保存 OCR 文字及方法；先確認工具可用，不承諾未執行的 OCR。公式、數值、單位與圖表必須回看頁圖。
5. 圖表逐一列入清單。先查看整頁與原圖說，確認各分圖、座標、圖例、箭頭、比例、誤差線、數值。裁圖後再看一次，避免只截到圖例或漏掉分圖。自動裁切的 pass 不能取代人工／模型視覺核對。
6. 缺頁或不清楚內容列入 `issues`，不得標 `done`。單位只有圖、沒有文字時，`text_review=not_applicable` 必須記原因，`visual_review` 仍需完成。

來源文字可用 pypdf、PyMuPDF 等工具；渲染可用 Poppler。工具不可用時找現有能力或誠實報告阻礙，不執行上游的 Linux 套件安裝器。依賴是執行環境條件，與教學規範分開處理。

## 防止漏讀與過度精簡

由子代理以原文章節完整閱讀為主，不靠題目關鍵詞命中片段拼講義。主代理嚴禁將整本書載入上下文；只接收目錄、分批交接與必要局部原文。將清單分成 `section / concept / equation / derivation / example / figure / table / exercise`。同一物件可關聯多個教學目標，但 ID 必須穩定。每個小節至少一個 section 項，每個重要概念及所有重要公式、推導、書中示範例題、圖表都各自登記；細節可合併到同一物件，不能省掉可追蹤性。

預設本章所有教學內容都須處理，包括註腳／側欄中影響理解的條件與反例。選入講義的原書圖表都要有文字解讀；其餘按重要性與頁數預算記壓縮或略過。原圖盡量保留，不能使用才重繪。裝飾圖可略過，但清單記原因。依學習目標挑選原書正文代表例題，完整詳解；未選例題與理由列入選題清單。章末原書題庫先完整辨識範圍，依學習目標挑原書代表題；原書沒有可用題目時才自編，清楚列出選題範圍與未逐題處理的題號；使用者要求全題時就全題處理。

每個來源項目只能是：

- `covered`：實際講義位置可回查，必要的內容核驗已完成。
- `compressed`：有具體壓縮理由及講義落點，保留必要推理與條件，完成相同的來源及內容核驗。
- `omitted`：列出具體理由；非裝飾內容依使用者已授權的全書篇幅取捨，記重要性、理由與影響；A級核心內容不可任意略過。
- `pending`：未處理或待核實，不得算成完成。

對重複內容，用 `covered` 指向共用說明並註明合併原因；不能說「已在別處講過」而不給落點。範圍外頁／段落在來源範圍定義排除，不能悄悄從已建的清單刪掉。

每個小節完成後：原書段落 → 概念 → 公式／推導 → 例題 → 圖表 → 講義位置，沿兩個方向回查。覆蓋率只表示清單是否處理，還要重看原頁確認清單本身完整。不訂講義字數／原文字數比；完整度由內容對照與推理連續性判斷。

## 長章續作

完整來源清單在磁碟上；一次工作載入當前小節的全文、相鄰銜接段、相依定義與術語，不強迫把整本書塞進上下文。完成小節即更新對照、問題清單與 `progress.json`。續作先比對來源雜湊，再讀進度、術語、上節結論及未解項目；已讀紀錄不能取代需要重核的原頁。
