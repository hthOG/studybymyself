# 中文正文與解釋次序

本檔修正2026-11-16兩冊講義對讀中實際出現的寫法，首次編寫與編輯正文前閱讀。[完整示範](../../../examples/reader-prose/lesson.md)提供能連續閱讀的小節；[比較紀錄](../../../docs/READABILITY-2026-11-16.md)列具體頁碼與觀察範圍。目標是把事情講清楚，不是套入更多格式或增加字數。

## 讀者看的是內容，不是製作過程

PDF不列「學習目標」「讀完應能」「先備知識」清單、目標對照表、編寫計畫、分層／Tier交接、逐句照錄說明、寫稿檢查點、篇幅分配、必留／壓縮指令或核驗狀態。這些只放outline、任務交接與工作log。使用者最新偏好優先於Codex範例中原有的目標／先備清單。

章首直接從原書的現象或問題開始，接著解釋必要概念。用到前章結果時，在需要處自然接回，如「上一節已求得距離，現在才能區分恆星本身的光度與我們收到的通量」。不要另印作者對讀者的能力宣告。物理假設、測量條件、符號定義與真正影響結果的限制仍屬教材，必須交代；它們不等於學習目標或製作備忘。

例如「此套座標有三個缺點（原書逐句照錄，寫作時當檢查點用）」應刪去括號內的製作說明，並把缺點寫成可理解的原因：「觀測地點改變，地平與天頂的方向也會改變；地球自轉時，同一顆星的高度和方位也會隨時間改變。因此，這套座標便於描述眼前的天空，卻不適合直接作為跨地點共用的星表座標。」這段仍需與實際原書內容核對。

## 用完整句子說清誰在做什麼

一句話先有明確的物理對象與動作，再連上原因或結果。主詞可在語意清楚時省略，不要讓「量級、自洽、條件、操作」變成代替推理的套語。

| 草稿中的問題寫法 | 修補方向與自然寫法示意 |
|---|---|
| 「新量中英並陳：徑向速度；橫向速度；自行……」 | 不把作者指令印出。可寫「把恆星的速度分成沿視線的徑向分量和垂直視線的橫向分量。自行（proper motion）描述天球角位置隨時間的變化。」再引入相關符號與關係式 |
| 「操作式：焦半徑和、短軸式、焦點極式、面積式」 | 說明現在要算哪個量及為何需要它；接著顯示當下使用的式子，不能把一串式名當正文 |
| 「條條使用點有二」 | 回到真正假設，例如「這一步把中心天體視為固定，是因為模型採用它的質量遠大於繞行物的近似。」只在來源確實使用此近似時採用 |
| 「塌縮成星須把能量輻射到太空輻射掉能量」 | 去除重複動作，交代主體：「星雲塌縮形成束縛系統時，會把一部分能量以輻射帶走。」實際條件仍依來源 |
| 「同一個式換兩次r」「上式組」「代入即得」 | 寫出選式理由、正在代入的量和關鍵中間式。讀者不能靠式號猜這一步如何完成 |
| 「三者乘積即資訊量，餘皆工程」 | 沒有定義與適用條件就不能包裝成定律；按來源分別說明各因素帶來的影響與取捨 |

英文術語在首次使用時配合定義自然給出，不必每一框都宣告「新量」。避免沒有主句的名詞堆疊、未經解釋的縮寫、指涉不明的「此量／其／前式」和不適當的語言混入。校閱時實際讀完整句，修復重複動詞、搭配不當及因果錯接；不能只檢查用字是否繁體。

## 讓閱讀順序跟上思考順序

先建立情境和正在解決的問題，再定義所需的量，在用到的地方顯示公式，接著解釋操作與結果。段落應各自完成一件事情：引入一個量、說明一次重要變形、解讀一項結果，或帶讀者讀一張圖。不是規定每段固定句數，也不要求印制式小標。

「公式單一權威」指一個數學內容只有一份可維護的定義，**不表示整章公式要在章首一次印完**。重要式第一次真正使用時就地顯示；不要讓讀者回翻幾頁找還沒學過的符號。公式檔可按物件／連續推導拆分，也可用不直接排印的命令定義供各節呼叫。不要把一整章的公式、推導和未定義符號塞入同一個章首input。章末速查表在概念與推導講清後再整理，不能代替正文。

若符號只為未來一節服務，留到該節再引入。引用已學過的結果可以用式號；首次引入、容易混淆或正進行關鍵計算的式子，應放在讀者眼前。不要為了避免顯示同一式而破壞可讀性；重用同一數學來源或引用編號，並避免重複label。

## 推導寫理由，例題寫走得通的解法

「為何選這條原理」「哪個條件在此使用」「從前式到後式做了什麼」必須由實際句子與中間計算回答，不能只印「操作目的／條件使用點／判讀／核對」後接片語。解題小標在複雜題有幫助時可以用，但每一部分仍須是完整的解說，不要求每題套滿同一組標籤。

例如二體化簡不能只說「代入即得約化質量」：先定義質心和相對位置，說明選用質心慣性系的條件，解出兩個位置，再顯示代回動能後如何合併。相對論的量測題要辨認同一對事件，指出在哪一系同地或同時、哪一個差量為零，再代入變換。這是補出原有內容的理解橋接，不是另加新教材。

題目問證明就給出決定結論的展開；問數值就交代輸入、單位、代入與答案；問繪圖或數值積分就真正給圖／演算法／結果，不能把「作圖即見」「縮步長檢查」當作已完成。每個小問均須有對應解答。必要計算不清楚時先減少重複題的數量，保留代表題的完整講解，不能把所有題都壓成答案摘要。

算式、數字與中文解釋必須互相支持。相差十倍不是「取位一致」；同一題的兩個不同答案不能用「量級」或「符號依正向」帶過。先回查原題、固定條件與參考系、重算並修訂採用結果；過程留log，正文呈現連貫的一套解答。

## 圖與文字共同完成一個解釋

直接嵌入實際原圖。圖說交代辨識圖所必需的符號與來源；正文帶讀者注意關鍵線段、區域或趨勢，並接到當下的公式或判斷。不能只把圖上所有字的位置逐一描述，卻沒有說明它們如何支持結論；也不把「這張圖必留」「寫稿重繪建議」印給讀者。完整照片、圖說、必要定義和推理關係應一起可讀。

## 自然不等於空泛，活潑不等於口號

提問式小標、短句及有用的比喻可保留，但緊接著要用具體概念與推理把它說明白。「待定係數三次瘦身」如果後面實際解釋每個條件排除了哪些係數，可以使用；只有「砍到剩三個」卻沒有理由，則需補寫。不要用「很好懂」「必背」「一眼即知」取代解釋，也不為避免生硬而添人物故事、裝飾背景或來源外比喻。

## 編輯要改出正文

寫完一節，先讀成品中的連貫正文，暫時不看outline、交接或自評。逐段指出讀者實際需要猜的符號、因果、操作或指涉，直接補寫該段，再回核來源及相鄰計算。報告要能說明「原句／缺什麼／改成什麼」，不是回覆「更自然、補細節」或新增一個pass欄。

最終不印本檔的檢查問題、目標、編輯紀錄或範例前言。字數、標籤、框數與機器通過都不能證明文字已好讀；來源、數學與實際PDF仍依原規範核驗。每冊頁限與指定冊數規則維持，不能以壓縮必要解釋來讓版面過關。
