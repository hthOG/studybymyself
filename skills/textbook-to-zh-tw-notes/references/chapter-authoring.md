# 逐章編寫操作規範：從原文證據寫成可自學的正文

本檔供主代理在**首次編寫章稿前必讀**，不是完成後才看的參考資料。續作只讀有關段落。讀者已學過基礎微積分；成稿使用臺灣繁體中文。編寫尺度範例見[完整小節示範](writing-example.md)，內容邊界及分類見[教學規範](pedagogy.md)。

## 解釋深度基準

現行標準是使用者已認可的四冊 Codex《黑洞物理導論》，具體頁碼觀察見[品質基準](codex-quality-baseline.md)。學習其問題、定義、條件、推導理由、物理解讀及完整題解的串接；不吸收vol版本的優點。舊84頁範例與照片僅為可選歷史參考，不作內容來源或深度上限。細節應用來補齊讀者重建原書關鍵推理所需的橋接，不靠增加主題或重複敘述拉長。

下列操作標準可獨立使用；若完整範例未隨當前工作提供，不需索取或取得該檔才能遵循本規範。

以具備基礎微積分的讀者為準，寫到讀者不必猜：為何此處選這條定律／模型或做這個代換；每個量指涉的物件、事件或系統、單位、正負／方向及定義域；來源給定的假設在哪一步會用到；重要代入、消元、積分、常數決定、取根及近似如何接續；答案代表什麼以及在哪些條件下適用。簡單算術可合併；來源已給定的經驗律或高等結論要標成給定，不能虛構證明。忠實說明／改述原書已有的推理不必標成 AI；為使基本微積分讀者接得上的新增簡易步驟須標「補充推導（AI 補齊）」。

完整例題的判讀、選法、符號式、中間計算、帶單位答案、物理解讀與合適的獨立核對都要能追讀；自測解答須逐小題給實際理由，核心題不能只寫結果、「略」或「自行查」。定性內容則保留原書支持的「觀察／條件→機制→影響→例子或表格證據」鏈；圖表需交代資料性質、控制條件、觀察如何支持結論、與相關公式的關係及不能推出的範圍，不猜圖上精度。

若 A 級理解鏈無法在兩冊內寫清，先把全書規劃調整為 3 或 4 冊；每冊仍以 PDF 全部頁面最多 100 頁為限。空間仍不足時，先刪重複、減少代表題數並依來源精簡 B／C 級內容；四冊上限不變，不能以縮薄核心理由或移出章末答案換頁。詳細退稿與修補定位見第 11 節。

首次編寫另讀[局部成稿示範](../../../examples/codex-style/lesson.md)，首次公式處理讀[公式核驗規範](formula-verification.md)。公式清單、CAS輸出、稽核標籤及變長的文字均不能取代正文中的推理橋接。

## 1. 編寫前實際要拿到什麼

首次編寫另讀[使用者範本寫法](reference-patterns.md)，按本章來源選用其公式鏈、數學卡點灰框、模型／圖表比較、完整比較表與自測、概念至應用題模式。把適用模式及要解決的卡點放入下述既有編寫計畫；不另做全章模式填表，不把所有模式強加每節。該檔說明 13 張照片範本的可選取法、內容邊界及退修條件。

先收齊本章範圍的來源交接、原書小節順序、逐頁定位、概念／公式／推導／題目／圖表清單、已核術語與前置定義。主代理不讀整書，按需開當前小節的公式檔、題幹、圖表及少量原文證據。只有摘要沒有公式、原題條件或圖說時，回派指定物件補件；不能憑摘要猜完整教學內容。

主代理在content/outline.md建立本章編寫計畫，至少記以下內容，完成後才寫該章正文；可隨來源回報更新，不必等待全書所有草稿：

| 欄位 | 要做出的決定 |
|---|---|
| 本章要解決的問題 | 用一句具體問題描述讀完能理解／計算什麼，不能只抄章名 |
| 可檢查目標 | 依來源寫「能解釋…原因／推導…關係／判斷…條件／求出…」，避免「了解本章」 |
| 先備與依賴 | 哪些前章定義、公式及數學會用到；給對應章節／物件ID，不重抄整章 |
| 小節次序 | 原書小節→講義小節；局部調序要記教學理由及來源落點 |
| 核心鏈 | 每節的問題、必要概念、關鍵公式、推導起點與終點、物理解釋 |
| 題圖配置 | 選入哪道原書題、哪張原圖來支援哪個目標；沒有可用題才考慮自編 |
| 篇幅 | 本章正文、推導框、圖、例題、複習、提示解答各預留多少頁，含在所屬冊上限 |
| 取捨 | A/B/C物件、理由、合併位置及略過影響；不能先刪未讀區段 |

規劃不等於成稿。交付的content/chapters/<章ID>.tex必須是讀者能直接閱讀的完整敘事；不得只有標題、來源清單、名詞解釋、公式或「此處解釋…」等待寫指示。

## 2. 章首如何寫

章首用短段落提出原書本章的具體現象或問題，說明既有知識在哪裡不足、這章引入的量或方法要解決什麼。接著簡列必要先備、3–5個左右的學習目標（依實際章內容調整，不湊數），以及本章到前後章的關係。先備只提醒會用的內容及回查位置；不另寫一章先備教材。

例：原書討論輻射傳輸，就指出要追蹤光通過物質後如何改變，為何只給總亮度不足；若原書沒有這個背景，不能另外編故事或添加新的物理主張。用中文解釋原書已存在的研究問題即可。

## 3. 每一小節的實際編寫循環

1. **問題與銜接段**：交代這節接續哪個結論、要回答什麼新問題。不要以「本節介紹X，公式如下」取代動機。
2. **現象與定義段**：先說原書討論的物理情境，再定義新量；首次中文（English），符號在使用前或同句定義，交代單位、方向／參考系。回答這個量描述什麼，以及為何此處需要它。
3. **建立模型段**：將原書給定的理想化、固定量、忽略項及邊界／初始條件寫在公式之前。區分定義、經驗定律、守恆關係、模型假設及推得結論，不把它們寫成同一類公式。
4. **推導段**：先交代「由哪條原理出發、想消去哪個未知量」，再依第4節寫推導。把數學操作與文字理由穿插，不整頁堆公式後只寫「因此」。
5. **結果解讀段**：得到結果後，用原書範圍內的論述解釋變數依賴、方向／正負、適用條件及與前述概念的關係；不能停在框出的答案。若原書已有極限、反例或誤解，在最容易誤用的位置說明。
6. **題圖支援段**：需要圖來理解幾何／趨勢時，就在相關論述附近放原圖與讀圖文字；需要解題示範時安排原書代表題。不是每個小節硬塞一題或一張圖。
7. **收束與轉場**：用一句話點明這節解決了什麼，下一節仍缺哪個部分。重點放因果銜接，避免一再重複同份重點表。
8. **即時對帳**：將來源物件ID對到具體段落／公式／題／圖，保存正文、公式與證據，再寫下一小節。源頭不清或核心推理斷裂時先補原頁證據，不能標covered後再說之後補。

這是編寫時的檢查順序，不是要求每節都印八個制式小標。正文主要用連貫段落；已知量、比較、步驟、術語等適合清單／表格的內容才用清單。

## 4. 重要公式必須寫到的程度

### 公式出現之前

明確定義符號所指的物件／事件、物理量類型、單位、正負／方向、參考系及必要的變數範圍；說明公式是定義、原書給定定律或本節待推結果。先說使用條件，例如穩態、均勻、球對稱、低速、弱場、同一參考系、同時測量等，並指出條件在哪一步被使用；但**只使用來源支持或理解該原式必須明示的既有條件**，不自行加一段來源外理論。

### 推導之中

- 寫出起始方程及來源；需要的幾何、座標與正方向先交代。
- 說明要得到什麼、為何選這項代入或操作；對重要代入、消元、變數分離、微分／積分、邊界代入、取根或近似各說數學理由及它在模型中連起／消去哪個量。簡單連續算術可合併，不能把關鍵積分或近似藏在「整理可得」四字。
- 積分交代變數、上下限／積分常數及使用哪個初始／邊界條件。近似交代小參數、保留階數及何時失效；等號與近似號不可互換。
- 記號更換、分母非零、根號正負、向量轉分量等會改變意義的步驟明說；不要為了讓式子相似而偷改原書符號。
- 每個關鍵式之間至少有能辨識操作及物理作用的說明，並在相關位置說明所用假設。不是把「等式兩邊相除」無限拆細，而是讓學過基礎微積分的讀者能自行接起推理。

### 公式之後

用文字回答：結果表示什麼？哪些量改變會如何影響結果？在剛才條件下才能使用的原因是什麼？原書提供哪些極限／對照／觀測支持？數學量綱或代回檢查必須在verification.md實際核驗；未在原書討論的額外物理極限分析不為填欄位而擴寫進教材。

### 主文、原書推導框與AI補步框

主文保留理解主結論必需的推導。原書已有的長／進階完整推導可放sourcederivation灰框，主文仍解釋起點、用途、關鍵想法及結論，不能只寫「詳見補充」。原書略去、但理解需要的簡易代數／微積分缺步放aisupplement灰框，標「補充推導（AI補齊）」及對照頁碼。原書未提供的高等證明不自行另證。

忠實中文重述、補上原書既有邏輯的銜接語，不必每句標AI補充；新增的簡易推導缺步及原書題目的AI解答則要可辨識。不要把「以原書為主」誤解成不能用清楚中文解釋原書。

## 5. 示範例題的成稿規格

每道選入的示範題，在題後就給完整解答，依下列內容寫成可讀解題：

| 部分 | 讀者需要看到的內容 |
|---|---|
| 題面 | 原書題號／頁碼、完整題幹與全部問項／必要條件；原題數據及單位不擅改 |
| 判讀 | 系統／物體／事件、已知量與待求量、各量的單位及正方向、參考系／定義域；辨認題目給定的模型條件 |
| 選法 | 說明選哪條原理／模型，以及題目哪些條件使它適用；交代先求哪個中間量與理由 |
| 計算 | 先建立符號關係，再依需要代數值；保留有教學意義的中間式、單位換算、根／近似選擇及多小題接續 |
| 結果 | 數值／符號、單位、方向／正負、有效位數，以及答案如何回應題目、代表何種物理量及適用範圍 |
| 核對 | 至少有適合該題的獨立代回／量綱／方向／數值合理性核對；來源確有說明時指出相關常見錯誤；真實核驗證據落盤 |
| 解法邊界 | 原書已有其他解法可比較；原書沒給不主動新增另一套方法 |

不得以「代入公式得答案」「同理可得」「留給讀者」作為完整詳解。原書例題本身省步，仍只能補必要簡易缺步，依補步規則標示；若關鍵高等方法超出來源，主文交代來源給定關係與使用條件，不假裝已另行證明。

原書沒有答案而由AI求解時明示「原書題目；以下為AI參考解答」，並實際驗算。錯誤答案不能因「原書內容」標籤而照收。

## 6. 原圖與表格怎麼融入教學

先確認此圖支援哪個段落，再放到鄰近位置，不先集中塞進章末。圖注保留原圖號與原書頁碼，內文引用該圖，不用「如下圖」當唯一定位。裁圖保留分圖、軸、單位、圖例、比例、箭頭與必要圖說；英文標籤保留時給中文對照，不直接覆畫到重要數據上。

讀圖文字依圖型選用，至少解釋讀者要看的對象、資料性質、比較條件與結論；指出來源中的哪項觀察支持結論、如何連到正文的量／公式，以及這張圖不能推出什麼：

- 函數／觀測圖：橫縱軸、單位、線性或對數尺度、各曲線／符號代表什麼、來源指出的重要區域與趨勢、其物理含義。取定量值時交代讀取方法及精度，不從示意線猜精確數據。
- 幾何／裝置示意：各物件、座標、尺寸、方向、觀察者／參考系及它們對應推導哪個量。不是只翻譯圖說。
- 表格：各欄量、單位、排序／分組、能比較的項目與原書支持的結論。若只選幾列，要明示節錄，不能讓讀者以為是完整資料。

未取得圖像、裁圖缺字、圖說缺失時回報補件，不能憑文字描述宣稱已核圖。確實無法使用原圖才依既有規範重繪；沒有資料就不造圖。來源本來無圖時不強行新增圖來湊七項要求。

## 7. 深入分析怎麼安排

遇到同一系統的原函數、平方、帶權分布或區間量，按[範本 P8–P10](reference-patterns.md)先辨定義、尺度和測度，再對應曲線；空間分類用名稱／原式／分圖對照，依原圖例解釋正負及色彩。敘述型內容仍要有來源支持的現象、機制、影響和證據鏈，保留比較條件／例外，但不強求每節都有公式。

把原書已有的假設、適用條件、對比、誤解、極限及概念關係放在最容易誤用的位置。寫清「哪項條件改變，前述哪步不再成立」，不要只貼一串警語。

若原書未討論某面向，且超出必要簡易補步，不自行擴寫；在verification.md記這項需求如何依來源處理。核驗用的獨立代回／量綱檢查可以留工作紀錄，不等於新增一節物理教材。

避免把現象、數學測量、觀測外觀混為一談。例如來源區分座標測量與光到達造成的視覺效果時，中文也必須保留；不能為口語化而把限定條件刪掉。

## 8. 章末必須實際寫出的內容

章末不是「本章重點如上」。需要可供複習與練習的內容：

1. **知識架構**：用短敘述、依賴箭頭或簡表說明概念如何接到定律、推導與應用；不能只複製目錄。
2. **帶條件的重點／公式表**：公式或編號、符號定義、使用條件及用途，避免無條件公式清單；引用權威公式，不重新抄一份可能漂移的式子。
3. **原書代表題與學習目標對照**：列來源題號及頁碼，交代各題練哪個目標；原書沒有題才自編並說明。示範題已在正文解完，不重印整道詳解湊頁。
4. **先提示、後參考解答**：自測／獨立題答案放該章末；每個小題一一對帳，提示只給解題起點，完整解答依第5節交代方法、步驟及判斷。概念題要有理由，開放題用參考要點，不能假造唯一標準答案。保留的核心題不可只列結果、寫「略」或叫讀者自行查資料。
5. **中英術語／符號表**：以本章實際使用為準，列中文、English、符號／單位與簡短含義；同符號在不同情境有不同含義時給對照。

來源題目不足時，在選題紀錄說明；不以每章固定題數強迫自編。所有章末內容都算入分冊100頁預算。

## 9. 來源與補充標記的讀者呈現

每節及來源變更的段落使用短註「對照原書p.X–Y」；題圖保留原編號。印刷頁碼未知就明寫「PDF第X頁（印刷頁碼未確認）」。工作ID、SHA、完成狀態、核驗表放工作紀錄，不印成正文的密集稽核欄位。

簡易新增推導用AI補步框；原書推導用原書推導框；確認訂正用correction框，附原頁及實際查證依據。不得讓「依原書」標記覆蓋新加的推論，也不把每句中文重述標成AI創作。

## 10. LaTeX落盤與避免空殼

主要章稿寫content/chapters/<章ID>.tex，章末提示解答寫content/answers/<章ID>.tex；學習架構、重點、題面與術語可在章稿尾，提示解答由冊入口接在該章之後。重要公式及推導寫content/math/<章ID>-<物件ID>.tex並input。來源圖與圖源寫content/figures/。不要另外維護另一份會與正式TeX分歧的全文Markdown。

模板既有環境：principle、examplebox、sourcederivation、aisupplement、correction，頁碼用sourcepage。章號／圖題號一致、label用章ID前綴，跨冊回查寫明冊／章／原書位置；不能留下未解析ref。只有參考此規範的模板片段仍屬骨架，正式交付前所有待寫內容必須消失。

自測／獨立練習可用 `selftestbox` 顯示完整題面、原題號／來源及章末答案定位；與題後立即詳解的 `examplebox` 分開。挖空表只在自測內使用，正式複習表須完整可查；章末有對應的逐格答案／理由。灰底微積分補步沿用原書／AI 兩種既有框，標題說明當前卡點，框後寫回原題的代入與結果，不另起與原書無關的數學課。

落盤前逐項實查：每個會重用／核對的核心原式是否已有獨立math檔，正文是否真正input而非另抄同式，解答是否引用既有label；一般數值代入可留例題內。僅在文字回報「公式單一來源」而實際仍全部內嵌不算完成。article模板中原書第7章應在章首設定section計數為6後再section，其他章類推；只寫label{ch7}不會讓印出的章號變成7。合成試寫可用測試目錄下math/相對路徑，仍遵守相同原則。

## 11. 每節退稿標準與編輯複核

主代理逐節完成後，在verification.md記該節的編輯複核：來源物件、實際正文落點、下表判斷、具體缺口及修正位置。這不是再寫一份章稿，也不是字數打分。

| 讀者檢查 | 退稿情形 |
|---|---|
| 能說出本節在解什麼問題 | 指出實際段落只有標題／名詞／公式，缺少欲解問題、引入新量的理由或前節銜接；修補到該段 |
| 能辨認各物理量與條件 | 指出首次出現的符號、單位、方向／參考系或變數範圍未定義，或某假設在實際推導中的使用點未交代；修補到該符號／步驟旁 |
| 能跟上核心推導 | 指出從哪個來源式跳到哪個稿件式、漏了哪項代入／消元／積分／常數／取根／近似理由；給來源支持的中間橋接與修補位置 |
| 能解釋結果與用途 | 指出哪個公式或結論後缺少物理解讀、變數依賴或適用條件，以及讀者會因此誤解什麼；修補在該結果之後 |
| 能照例題重做 | 指出題目哪個條件沒連到選法、哪個中間式／單位／問項答案或核對缺失；修補在題面後的相應解題步 |
| 能閱讀選入圖表 | 指出圖表編號及稿件落點，具體列出缺失的軸／資料性質／控制條件／支持結論的觀察／公式關係／限制；修補在圖表旁 |
| 能完成章末複習 | 指出章末哪道題的哪個問項只有結果或無解答、缺哪段理由；補上逐問答案，或指出摘要架構／帶條件表的實際缺口 |
| 能查回來源並辨識補充 | 指出錯誤或不明標示的頁碼／段落，以及哪些句子是來源邏輯、哪些是 AI 補步／訂正；修補該註記，不用整體 pass 代替判斷 |

退稿回報要能定位到來源物件／原頁、稿件段落／公式label／題目問項，寫出缺少的橋接及來源可支持的修法。只有「需要更詳細」「未通過」或狀態標籤，沒有實際落點與修補方向，不足以完成編輯複核。

來源確實沒有某類物件時記不適用及依據；不能造物件來過表。必要缺口未補齊時，保留needs_fix／unresolved，不能先填pass。機器check通過後仍要問：只看這份章稿、具備約定先備的讀者，是否能重建主線並完成選題？若仍要靠猜，就回正文補清楚，不能用更多檢核標籤取代解釋。

## 12. 篇幅不足時的具體改法

先合併重複導入／重複定義，刪重複題及不支援主線的C級細節；精簡B級敘述，保留會改變結論的條件。例題保留代表方法的完整一題，比把多題都壓成答案有用。原圖可合理縮放／排在相應文字旁，但軸字與公式須可讀。若兩冊無法容納可跟隨的核心解釋，先增至3或4冊；仍緊張時再減重複及非代表題、依來源精簡B／C級內容。不能刪關鍵推導理由、把所有解答移出冊外、縮成小字，或用「詳閱原書」代替保留核心的解釋。所有取捨寫selection-log，再核受影響依賴及實際頁數。
