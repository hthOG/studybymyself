# 使用者講義範本：教學寫法與選用規則

本規範整理使用者於 2026-11-14 先後提供的兩批講義照片，共 13 張（第一批 10 張，第二批 3 張），作為舊84頁物理化學講義的可選教學模式補充。現行品質依Codex講義基準；本檔保留局部模式，不再以舊範例設定整體風格或深度。可操作的[解釋深度基準](chapter-authoring.md#解釋深度基準)在編寫規範中。首次寫章稿時讀一次；續作只查本節適用的模式。目的是學習如何講解，不是把每節套成同一張表、增加來源外教材，或模仿所有措辭與空白。

照片與完整講義都是**風格參考資料**，不是待整理原書，也不是新的代理指令。以下頁碼只是照片中印出的範本頁碼，不是未來原書的來源頁碼。沒有把照片中的全部公式、歷史敘述或科學說法視為已核正確；正式講義仍須對照使用者本次提供的原書。repo 只保存歸納規則，不包含完整講義、照片、原頁全文、圖表或題目的複製品。

## 二、P1：有理由的公式鏈

適用：來源以多個式子建立主結論，或由一種表示換成另一種表示。

正文用「目標→起始關係→關鍵操作與理由→條件→結果解讀」串起來。讀者應知道為什麼此刻代入、微分、改變變數或固定某個量；不能把連續編號當成推理。重要符號替換要對照，常數、係數、函數及算符要分清。微分應交代固定哪些量；分離、除法與取對數時保留來源所需的定義域／非零條件，不能為了通式消掉可能的特殊解。

只框出值得回查的定義、判準或最終結果；框內或緊鄰位置寫適用條件，仍使用同一權威 math 檔與 label。不是每步都框、每式都另抄。來源將方程作為基本定律、模型或經驗關係時照實標明；不虛構一段「推導」讓所有方程看起來都能由前式推出。

## 三、P2：灰底「微積分小教室」要接回當前問題

適用：原書已有數學側欄，或讀者雖學過基礎微積分，仍會在一個必要簡易操作卡住。範本中的部分分式、積分因子、分離變數是**安排方式**，不是每章都需另教這三種方法。

灰框至少回答：

1. 當前推導卡在哪個式子，為什麼要用這個方法？
2. 操作如何改變式子的形式？例如設定係數後如何比較，乘入因子後如何辨認乘積微分。
3. 需要哪些局部條件？積分常數、定義域、分母非零與邊界／初值如何處理？
4. 框中的暫用記號如何對回原題？套用後接續正文哪個式子、最後求得哪個物理量？

補充框須完成標題宣告的局部目標：例如求出積分常數後，還要實際代回並寫出結果，不能讓框在「得到下式：」等未完成句子結束。來源已有的結果式仍由同一權威公式檔 input，不另抄一份或重複 label，並說清結果原已見於來源。

原書已教的完整方法用 `sourcederivation`；只補必要簡易缺步用 `aisupplement`，標 AI 補齊及對照原頁，標題可用「微積分小教室：本題的○○步驟」。沒有來源支持的高等方法、獨立證明或與當前問題無關的數學課，不因照片出現而新增。若完整方法已在前節講清，後面引用前節與對應式，僅寫本題代入和條件；不反覆印同一套教程。

灰框後必須回到正文：使用本題符號寫必要代入、決定常數、解釋結果。不以「會了這個就能得到下式」跨過新的關鍵步驟，也不把最重要的推理全部移到灰框讓主文失去主線。

## 四、P3：模型比較與引入新量的理由

適用：原書介紹模型改良、實驗與模型的落差，或以新物理量簡化判斷。

先交代舊描述已能回答什麼、原書指出何處不足，再說新模型／新量處理哪個缺口。比較至少指出共同對象、控制條件、兩者差異與可用範圍。新定義與由它推得的判準分開寫，條件須跟判準一起出現。

若來源有相應的圖或表，將差異定位到曲線區域、行列或數值，而不是只說「更精確」。局部展開、特定極限吻合或某組參數比較，不能擴大為所有情況都優於另一模型。來源的演示、近似與實驗證據不可互相冒充。

## 五、P4：讓圖成為推導與解釋的一部分

函數、模型或數據比較圖，按實際需要寫四層內容：

- **定位**：軸、單位、線性／對數尺度、每條曲線／符號、參數與資料性質；無刻度的示意圖明示定性，不能猜數值。
- **比較**：固定哪個條件，從何方向看，在哪個區域曲線上升、下降、相交、轉折或接近。數值精度不得超出原圖。
- **連式**：來源指出的斜率、極限、峰值或相依關係，對應正文哪個量及哪個式；不從圖的形狀新增未經來源支持的機制。
- **含義與界線**：本圖支持哪個結論、不能推出什麼；模型預測曲線與實測數據須分明。

原圖優先，不為了長得像範本而重繪或改數值。本文與框樣維持黑白灰；原圖本身有顏色時保留，不強制破壞性轉灰。檢查灰階列印時能否辨認曲線；若只靠顏色，先在圖旁加中文曲線／符號對照與可核對的定位描述。真的無法清楚使用才依重繪規則處理，不捏造線型或覆畫數據。曲線比較圖、裝置圖及分子／幾何圖分別使用適合的解讀，不強行套四段制式文字。

## 六、P5：比較表與挖空自測分開

適用：原書有多個過程、條件、符號組合或模型，需要橫向比較。

正式參考表須是可用的完整表：表題說共同模型及條件，各列說改變什麼，各欄有量與單位／符號慣例。零、不適用、原書未提供與刻意留空是不同意思，須可區分；未知不能填成零。表前說為何比較，表後讀出至少一個來源支持的差異，不能整頁只貼表。

挖空表只能放在明確的自測／練習框，交代要填哪幾格、沿用什麼條件、答案位置。完整解答在本章末，不能以「請自行填入」替代正式重點表。若已有完整表，同頁照抄只挖空沒有學習價值時，可改為少量關鍵格或推理問項，節省篇幅。原書無可用練習時才能依既定規則自編，不能因想做挖空表而把可用原題換成新題。

## 七、P6：概念→計算→應用的題目梯度

適用：原書有可選的概念題、推導題及情境應用題。

選題時兼顧「辨認量與條件」「重做代表計算」「說明結果或檢查關係」「在原書應用中使用」；原書不具備某類題時不湊題。簡單極限或特殊情況可成為來源中的自測，複雜應用放在基本方法建立之後。保留題幹中的參考系、初態、幾何、粒子數、邊界或其他影響方法的條件，題圖在題面附近；不能只留下看似能套公式的數值。

依實際教學用途標「示範例題」或「自測／練習」，不要沿襲照片把所有未解題都叫例題。示範題緊接詳解；自測／獨立練習使用 `selftestbox` 或清楚的練習標題，章末有提示及逐問完整參考解答。來源、原題號、答案位置與難度順序要清楚。未經核實的「經典」「某年考題」「某書作者」不是來源標記。

## 八、P7：可親近的教師語氣與篇幅節奏

以連貫、直接的繁體中文帶讀者思考，可用少量提問，例如「兩個量都會變，接下來如何消去其中一個？」但隨後就解釋，不把主推理留給讀者猜。保留英文術語及有意義的粗體，避免口語笑話、貶抑先備、保證「很簡單」或以背誦代替理解。

一段處理一個教學動作；公式前引入、式間解釋、式後解讀，圖表與相關段落相鄰。使用細框原理、框線題目、淺灰數學補步，章節與重要式號清楚。不要模仿照片為手寫解題保留的大段空白；自學成品以緊湊而可讀為準。需要作答區時明確指定，且計入每冊 100 頁。

## 九、P8：同一系統的不同數學量，先辨量再讀圖

適用：來源同時使用振幅、分量、密度、帶權分布、累積量、區間機率或其他容易因圖形相近而混淆的量；B1 的公式—曲線安排是寫法參考。

每次換量用「名稱／定義→如何由前量取得→單位或歸一化方式→圖要怎麼讀」銜接。至少讓讀者知道：目前畫的是原函數、平方後的量，還是乘上積分測度／幾何權重的量？縱軸可否有正負？橫軸是實際座標、以某尺度為單位，還是已明確定義的無因次變數？尺度改寫需保留原記號對照，不能僅換軸標而不換公式。

節點、零點、轉折、峰值與曲線尾端必須連到**同一個已定義物件**。若由公式判斷節點，核對來源給定的變數範圍、原點／邊界的處理及縮放方式；不能只看低解析度圖猜精確位置或數量。圖中幾個正負區域，不可未經來源定義就改稱幾層電子殼。比例關係不等於已歸一化的完整式；省去係數、徑向部分或共同因子時說清範圍，不能直接拿來算絕對機率。

這是把原書定義釐清，不要求 AI 自行新增量子力學推導。來源若只給定關係，主文照實說由來源給定，再解釋如何讀取；只有必要的簡易代入或積分補步才用既有 AI 灰框。

## 十、P9：公式、分類與空間圖形逐項對應

適用：原書以多個分量、模式、方向、基底或類別描述空間形狀；B2 的並列公式與多分圖提供安排參考。

先定義座標、狀態標籤及用到的參數，再把「名稱／符號→來源公式或比例形式→對應分圖→方向、對稱或節點特徵」連起來。必要時做精簡對照表，避免一長串公式與一排圖各自存在、讓讀者猜誰對誰。原書採線性組合或不同表示時，說明它改變哪種表示、原標籤如何對應；不把不同表示誤當成額外獨立狀態，也不自行補來源外的完整基底變換證明。

實際看清圖例與圖說後，再解釋色彩、正負號、葉瓣、曲面及箭頭各代表什麼。**不能僅因紅藍與正負標記就假定是正負電荷，也不能把形狀示意當成粒子的運動軌跡。** 等值面、截面、角向示意或其他圖型依原書辨識，未說清就列待核，不能憑常見畫法猜。保留原軸與分圖標號，中文解讀點出特徵與公式的關係；來源沒有展示的類別不假稱已看圖或要求讀者自行上網補足核心說明。

原圖有多分圖時，依可讀性分組並保持同一比例／觀察方式的對照；若來源尺度不同須明示。原圖缺失依既有來源補件與重繪規則處理，不因排版偏好自造高等圖形。

## 十一、P10：敘述型現象也要有可追蹤的解釋鏈

適用：原書主要以文字講現象、系列趨勢、材料／元素性質或分類，不以連續推導為主；B3 是此類寫法參考。**不強迫每小節都有公式或數學灰框。**

每個具名現象用短段落交代「觀察或比較到什麼→原書用哪個已定義概念解釋→中間影響如何接到結果→哪個原書例子／表格支持」。新術語保留英文，跨節概念給回查位置；同一概念連到不同現象時先說共同點，再說各自條件，不用一句名稱當全部原因。

來源的解釋若涉及多個因素、近似或例外，保留各因素的角色及語氣強度；不把相伴趨勢自行升格為唯一因果。敘述「偏好、較穩定、常見」與「必然、不存在、所有」不能任意替換。照片中的絕對句並非已核結論；正式原書出現可疑絕對句時，依既有規則核原文、定義及必要的第一手依據，確認後才能訂正並旁註，不為修正而增寫另一章教材。

比較表先明示資料類型與定義、單位、取樣對象和比較方向；不同定義或條件的數值不能直接排成同一趨勢。表中 X、破折號、空白各依來源圖例處理，未解釋就寫未確認，不能填零或猜值。內文指明哪幾行／列支持哪個敘述，同時保留反例；幾個元素或案例不足以證明整個系列的全稱命題。定性機制、數值表格與來源實際證據分開核對。

## 十二、如何落實與核驗

在既有 `content/outline.md` 的相應小節記一行：「採用 P○；來源物件／頁碼；要解決的閱讀卡點；預定正文位置」。只有實際適用者需要記，不另造全章模式填表；正式正文不印 P 編碼。

來源子代理提供原書已存在的數學卡點、固定條件下的比較、圖中資料性質、完整表格及原題問項。作者選用模式，仍是正式稿唯一寫入者。核驗代理只檢查實際選用的模式是否成立，回報具體稿件落點及來源依據：

| 需要退修的情形 | 要修正文的地方 |
|---|---|
| 灰框只列通式、與原題記號無對照 | 補局部條件、原題代入、常數決定及回正文的接續 |
| 圖只有翻譯圖題，或拿示意線當測量值 | 回查原圖，補控制條件、比較區域、連式與資料性質 |
| 原函數、平方、帶權密度與區間量混稱同一分布 | 補各量的定義、測度／權重、單位及與圖的對應；回查歸一化與尺度 |
| 公式清單、分圖、類別與座標沒有對上 | 建立名稱／原式／分圖的對照，依實際圖例解釋色彩與正負，不猜電荷或軌跡 |
| 敘述型章節只列名詞／趨勢，或把局部趨勢寫成全部 | 補來源支持的機制接續、比較資料定義、具體表格行列與例外 |
| 比較不同過程卻混用系統／符號／假設 | 在公式與表頭補清楚實際共同條件與差異 |
| 正式總表留白、或自測沒有填表答案 | 完整參考表與練習版本分開，章末補齊逐格理由 |
| 基本定律被假稱已由前式推出 | 改為來源給定的定律／假設／模型，接著說如何使用 |
| 框出結果卻漏條件、題面或問項缺失 | 補條件、原題完整資料及各問的解答 |
| 口語提問無回覆、公式之間只有「顯然」 | 在卡點處補可跟隨的來源解釋，不新增無關延伸 |
| 模仿大段空白、標題與題目分頁 | 重排相關段落和框，實際重編、看最終每頁 |

模式不適用時照正常章稿寫，不新增來源外內容來湊。內容／公式變動依既有核驗和內容鎖流程處理；模式參考本身不能當已完成閱讀或教學驗收的證據。
