# 自造的局部來源：加速座標

本頁是測試作者與核驗者的短來源，不是Frolov與Zelnikov原書節錄，不帶真實原書頁碼，也不能拿來填全書來源覆蓋率。

給定二維Minkowski線元素與座標變換（c=1、號誌−+）：

\[
ds^2=-dT^2+dX^2,\qquad T=\rho\sinh\eta,\quad X=\rho\cosh\eta,\quad \rho>0.
\]

T、X、ρ有長度單位，η無因次，取未來方向。固定ρ的觀察者滿足 ds²=−dσ²，σ是其固有時、取零點使η=0時σ=0。四加速度以自身固有時定義，a^μ=d²x^μ/dσ²，大小為 \(\sqrt{a^\mu a_\mu}\)。

來源任務：把變換代入線元素，解釋不同ρ上η與σ的關係，求固定ρ世界線的加速度。解答用基本微分、雙曲函數恆等式即可。不可從本頁聲稱已推得Hawking或Unruh溫度。

練習：固定ρ=ρ₀的觀察者，η由0增加至2，經過多少固有時？另一觀察者固定ρ=2ρ₀，在同樣η區間經過多少固有時、加速度與前者之比為何？這是沿兩條指定世界線的計算，不聲稱比較同地重逢的鐘。
