## 實際執行

1. 將逐章編寫 prompt、必讀規範及兩頁來源交給獨立子代理，要求直接產出中文 LaTeX 章稿和章末解答；未要求它編譯、上網或安裝。
2. 主代理閱讀產出並對照 S2，檢查來源條件、推導補步、例題題意與選法、表格解讀、練習問項及章末解答。這是第二位 agent 的內容審閱；子代理的 verification.md 本身是自查，不能冒充獨立驗收。
3. 初稿把重要原式直接放在正文，且章號標籤沒有設定實際章號。要求子代理修正後，式 7.1–7.3 各置於獨立 math 檔案，章稿以 input 引入；article 的 section 計數器設為 6，下一節顯示 7。這兩項也補進正式編寫規範與 prompt。
4. 發佈副本將工作區專用 input 路徑改為本範例目錄的相對路徑；保留公式內容。遞迴展開入口的 input，確認全部檔案存在、沒有越出範例目錄或循環；7 個唯一標籤及 8 次引用均能對應，三個原式編號各出現一次。
