# 實際試寫：平板中的熱傳導

這是一次有界的 agent 編寫試驗，使用完全自造的兩頁英文[來源 S2](source.md)。頁碼 201–202、章號及題號都是測試用標記，與任何真實教科書無關，不得引用到正式講義。

子代理實際讀取[逐章編寫 prompt](../../prompts/write-chapter.md)及其指定規範，再產出[中文章稿](chapter.tex)、[章末提示與完整解答](answers.tex)及[自查紀錄](verification.md)。主代理逐項對照來源審閱，發現並修正公式檔案與章號設定的缺漏；具體結果及限制見[主代理審閱](parent-review.md)。

這份樣稿展示實際應寫出的內容：概念與物理量區分、模型與條件、必要的簡易積分補步灰框、代表例題選法理由與完整計算、來源表格的中文解讀、章末架構與帶條件的公式整理，以及原題的提示和完整解答。它只是兩頁來源的寫作試驗，不能證明完整原書的處理品質。

## 可選的本機排版

準備好 repo 的 XeLaTeX 與中文字型後，在本範例目錄執行兩次：

```text
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

[入口模板](main.tex)使用共用模板的排版設定，所有 input 路徑均相對於本範例目錄。重要原式放在 math 目錄並由章稿引用；答案在本章之後。不要將此範例的手動章號設定直接拼接到其他章而不檢查順序。

初次試寫只查核數值、來源對應、輸入檔案與標籤引用。2026-11-14 已在 Windows 的 MiKTeX 26.5／XeLaTeX 實際編譯兩次，產生 3 頁 PDF 並檢視全部頁面；中文使用微軟正黑體、英文使用 TeX Gyre Termes。修正例題公式的斷行、解答標題斷段、孤立節標題及答案前不必要的換頁；數學內容不變。最終沒有缺字、未解析引用、水平或垂直溢出的 log 訊息。這不代表 Ubuntu 或真實全書已驗收；換字型或環境後仍需重新檢查。
