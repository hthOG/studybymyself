子代理實際讀取[逐章編寫 prompt](../../prompts/write-chapter.md)及其指定規範，再產出[中文章稿](chapter.tex)、[章末提示與完整解答](answers.tex)及[自查紀錄](verification.md)。主代理逐項對照來源審閱，發現並修正公式檔案與章號設定的缺漏；具體結果及限制見[主代理審閱](parent-review.md)。

## 更新後的詳細版

使用者補充完整 84 頁物理化學範例後，明確要求成品的核心解釋與解題比範例更詳細。依更新後的規範，以同一份[兩頁合成來源 S2](source.md)進行獨立前向試寫；產出存於 [detailed](detailed/main.tex)，包含[正文](detailed/chapter.tex)、[章末提示與完整解答](detailed/answers.tex)及四個權威公式檔。試寫代理只取得來源及新規範，未照抄本目錄既有章稿。

詳細版讓讀者看見常數熱導率在哪一步使用、兩個邊界如何決定積分常數、溫度二階導數為零與溫度為零的區別，以及熱通量／總熱傳率的方向、單位與逐步計算。完整保留來源例題、表格及習題問項，未擴充其他傳熱模型或另編題目。完整題面與溫差單位的初稿缺漏已修正並獨立複核，見[本輪審閱](parent-review.md#詳細程度補強後的獨立前向試寫)。

在 `detailed/` 目錄執行兩次以下命令，即可重建這份 5 頁試寫；正式交付仍須在自己的環境核對 log 與全部頁面：

```text
xelatex -disable-installer -no-shell-escape -interaction=nonstopmode -halt-on-error -file-line-error -recorder main.tex
```

`-disable-installer` 為本輪 MiKTeX 的設定；使用 TeX Live 時省略該旗標。原有 3 頁版及下方補驗紀錄保留，分別記錄各版本，不能把本例當成真實全書、原圖或跨平台驗收。
